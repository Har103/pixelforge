How it holds up

Live, both ways

WebSocket by default with an automatic fallback to Server-Sent Events, so a canvas still syncs on a network that will not carry an upgrade. Updates are batched on a 50 ms tick — a paint storm costs a handful of frames a second, not hundreds.

It remembers

Every placement is appended to Postgres and the grid is snapshotted, so a restart brings the canvas back exactly as it was. Scrub the whole history, or export it as an animated GIF.

You are the moderator

Whoever makes a canvas can pause it, lock a region, clear it, block a painter, or undo everything one person drew — with the pixels underneath restored from the log, not guessed.

Nothing under the hood

Go standard library only. The Postgres driver, the WebSocket server, the password hashing and the image encoders are all written here — go.mod has no dependencies at all.
